# Dokumentasi Portfolio

Folder ini berisi bahan pendukung dan dokumentasi visual project.

## Isi

- `design-guides/` — evaluasi dan panduan palet warna portfolio.
- `screenshots/blockchain/` — tangkapan layar project blockchain.
- `screenshots/expense-tracker/` — tangkapan layar desktop dan mobile expense tracker.
- `screenshots/overtime/` — tangkapan layar project overtime.

File gambar di sini merupakan dokumentasi; aset yang digunakan website tetap berada di `public/assets/` dan `src/assets/`.
